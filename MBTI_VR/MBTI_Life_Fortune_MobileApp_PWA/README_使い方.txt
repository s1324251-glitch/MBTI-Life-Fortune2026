【スマホでアプリとして使うには】
PWAは https で公開する必要があります。
Netlify または GitHub Pages などにフォルダを公開してください。

iPhone：
SafariでURLを開く → 共有 → ホーム画面に追加

Android：
ChromeでURLを開く → アプリをインストール
またはホーム画面に追加

【追加した最初の画面】
・MBTIを知っている → アプリへ
・MBTIがわからない → MBTIの簡単な説明
・日本語の無料診断サイトへのリンク
・ホーム画面に追加する案内
